## [1] 引入基本面因子（PE / PB / 市值 / 换手率）

**类型**: feat
**影响范围**: `src/data/fundamentals.py`（新增）, `src/data/pipeline.py`, `src/features/indicators.py`, `src/data/tdx_reader.py`, `main.py`
**关联**: 后续将基于此进行第二步（资金流向因子）

### 问题 / 动机

当前模型仅使用技术因子（MA、MACD、ATR 等），完全没有基本面与消息面信息。
A 股是散户主导的情绪市场，情绪机制完整链条为：
`消息/事件 → 情绪放大 → 资金流入 → 价格偏离基本面 → 回归`

现有模型只在第三步之后介入，丢失了估值锚作为反转信号、规模因子作为情绪弹性指标等关键信息。
本次为第一步：加入估值因子（PE/PB/PS/PCF）、市值规模（总市值/流通市值）、换手率。

### 变更内容

**新增模块** `src/data/fundamentals.py`
- akshare 接口：`stock_value_em(symbol=code)`
- 拉取列：`pe_ttm, pe_static, pb, ps, pcf, peg, market_cap, float_market_cap, total_shares, float_shares`
- 数据范围：2018-01-02 至今，每日一行
- 缓存路径：`data/fundamentals/{code}.parquet`

**修改 pipeline** `src/data/pipeline.py`
- 新增 `_merge_fundamentals()`：读完 TDX K 线后左连接基本面
- 用 `volume / float_shares × 100` 推算换手率（TDX 本地数据无此字段）

**新增因子** `src/features/indicators.py::_add_fundamental_features()`
共 10 个衍生因子：

| 因子 | 含义 |
|------|------|
| `pe_ttm_log / pb_log / ps_log / pcf_log` | 估值 log 变换（截面 Z-score 后体现"贵不贵"） |
| `market_cap_log / float_mc_log` | 市值规模（小盘股情绪弹性） |
| `pe_ttm_self_pct / pb_self_pct` | 自身 252 日历史分位（纵向贵不贵） |
| `float_shares_chg20` | 流通股本 20 日变化（增发/回购痕迹） |
| `peg_value` | PEG 直接保留 |

特征列总数从 46 → **56**。

**新增过滤** `src/data/tdx_reader.py::is_active_in_period() / get_active_tdx_codes()`
- 只读 `.day` 文件最后 32 字节判断该股票在 START_DATE 后是否仍有交易记录
- 用于在 `fetch-fund` 前过滤退市/长停牌股（5769 → 5641，剔除 128 只）
- 扫描全市场耗时仅 1.3 秒

**新增 CLI 子命令** `main.py`
- `python main.py fetch-fund [--sample N] [--delay S] [--refresh]`
- phase1 启动时检查基本面缓存数量（< 1000 给警告）
