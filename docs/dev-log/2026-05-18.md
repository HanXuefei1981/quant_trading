**类型**: feat
**影响范围**: `scripts/fetch_fund_flow_local.py`, `tests/test_fetch_fund_flow_local.py`
**关联**: [2026-05-14 #1] 资金流向因子待跟进项

### 问题 / 动机

东方财富资金流向 API（akshare）存在 IP 地理限制——开 VPN 时因出口 IP 非国内而被拒绝。
解决思路：单独提供一个脚本，让用户**关 VPN 后在终端手动运行**，批量下载并缓存到 `data/fund_flow/`，
主流程（Phase 1 特征工程）只读缓存文件、不触发网络请求，从而绕开 VPN 冲突问题。

### 变更内容

**新文件 `scripts/fetch_fund_flow_local.py`**，包含四个核心函数：

| 函数 | 说明 |
|------|------|
| `get_all_codes()` | 从 `data/raw/kline/` 扫描所有股票代码 |
| `get_pending_codes()` | 过滤已有缓存的股票，返回待下载列表 |
| `download_all()` | 批量下载主循环：tqdm 进度、连续失败熔断、间隔控制 |
| `print_header()` / `print_report()` | 开始/结束摘要输出，失败列表写入 `_failed.txt` |
| `main()` | CLI 入口：`--delay`、`--max-errors`、`--codes` 三个参数 |

**测试文件 `tests/test_fetch_fund_flow_local.py`**：14 个测试，覆盖全部公共函数，TDD 红→绿→重构全流程。
