# 2026-05-07 开发日志

## [1] 发现 market_features.parquet 末尾 5 天数据缺失问题

**类型**: fix
**影响范围**: `config/settings.py`, `src/data/pipeline.py`（行为受影响）
**关联**: 间接触发 [2026-05-11 #1] 的 sync 工作流改造

### 问题 / 动机

回测结果末期资产归零（-97%），定位发现：
- `market_features.parquet` 的最后 5 个交易日缺失
- 根因：`add_cross_sectional_label()` 后做 `dropna(subset=["label"])`
- 每只股票最后 5 行的 `future_ret = close.shift(-FORWARD_DAYS) / close - 1` 必然为 NaN（因为没有未来 5 天的数据），所以 label 也是 NaN
- 这些行被全部 drop 掉

进一步追查：本质是 `END_DATE` 设置过早（如 `20260508`），导致即使通达信本地有 `2026-05-11` 的数据，pipeline 也只读到 `2026-05-08` 之前。再叠加 `shift(-5)` 标签，使 `2026-05-01` 之后的标签都是 NaN，最终只剩 2026-04-28 及更早的数据。

### 变更内容

- `config/settings.py`：`END_DATE = "20260508"` → `END_DATE = "20991231"`
- 让 pipeline 永远使用全部已下载的 TDX 数据，未来更新数据时无需手动修改配置

### 验证方式

- 重新跑 phase1，确认 `market_features.parquet` 最新日期跟随 TDX 数据
- CLAUDE.md 已记录此问题，作为长期警示
