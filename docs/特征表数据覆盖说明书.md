## 五、已知问题与注意事项

1. **EPS 共识两列全表 100% 空**——`eps_snapshot` 仅点位快照、历史无法回填，是死特征，建议从模型特征剔除或换可回填的 EPS 接口。
2. **pe_ttm 新旧数据源约定差异**——tushare daily_basic 对亏损股返回 NULL（近期 ~28%），而历史旧 akshare 源仅 ~7.6%，存在轻微分布漂移；当前由 LightGBM 原生处理 NaN，暂不阻塞。
3. **基本面缺口已修复**——2026-05-14~05-26 曾因 tushare token 过期（3 天时效）出现 ~99% 估值列缺失，已于 2026-06-01 用 `fetch-fund --since` 补全。
4. **推断截面**——scan 读 features 表最新日（当前 05-29）；该日为无标签行，特征已预处理，直接使用。
5. **预处理后取值**——表中因子均已经过 MAD 去极值 → 板块中性化 → 截面 Z-score；原始量纲值不在此表（在 `fundamentals`/`fund_flow` 等原始表）。
